# filestore tests

`filestore_behavior` is registered with CTest. It checks empty, exact-size and partial final chunks; persistent manifests and verified reads; rejection of unverified chunks; bounded manifest/HAVE pages; atomic assembly of out-of-order multi-page HAVE snapshots; deterministic two-holder placement; metadata exchange; explicit insufficient-peer and unavailable-replica events; queue-full retry; and repair after a local chunk is corrupted. A five-store simulation distributes a deterministic 2 MiB file across four peers, joins a fifth peer while its fetch queue is full, verifies old copies remain until replacement storage is confirmed, then checks exact placement after retry and after the original publisher leaves. This tests M3's state machine through fakes; it does not claim real UDP integration.
